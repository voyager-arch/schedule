간단 모드와 고급 모드를 나누어 주간 학습 계획을 자동 생성합니다.

간단 설정
간단 모드는 공부 가능 패턴과 과제 목록만 입력하면 됩니다. 처리 속도, 휴식, 분할, 우선순위는 기본값으로 자동 설정됩니다.
형식: 과제명 / 분량+단위 / 마감요일
예: 수학 문제집 / 40쪽 / 수요일
1. 시간 입력 방식
가능한 시간을 직접 넣는 모드입니다. 예: 월요일 18:00~22:00.
2. 기본 하루 범위 / 하루 최대 공부량
3. 요일별 가능 시간
4. 집중 / 휴식 설정
5. 과제 목록
왼쪽에서 설정을 입력한 뒤
시간표 생성 버튼을 누르세요.
